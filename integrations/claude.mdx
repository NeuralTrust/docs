## Deployment options

For local setup, use the Claude Code [TrustGuard plugin](/integrations/claude-code#trustguard-plugin)
or [TrustGate MCP connection](/integrations/claude-code#connect-to-trustgate).
For organization-wide setup, see [Claude Enterprise deployment options](/integrations/claude-enterprise#deployment-options).

## Before you start

Check the prerequisites for [Claude Code](/integrations/claude-code#before-you-start)
or [Claude Enterprise](/integrations/claude-enterprise#before-you-start).

## Claude Enterprise

To evaluate model requests across your organization, configure the
[Claude Enterprise inference hook](/integrations/claude-enterprise#inference-hook).

## Claude Code

To evaluate prompts, commands, and tool executions locally, install the
[Claude Code TrustGuard plugin](/integrations/claude-code#trustguard-plugin).

## Organization connectors

To manage MCP tool access across your organization, configure a
[Claude Enterprise organization connector](/integrations/claude-enterprise#organization-connectors).

### Claude Code CLI

To connect a local Claude Code client to MCP tools, follow
[Connect to TrustGate](/integrations/claude-code#connect-to-trustgate).
