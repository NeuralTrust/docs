description: "TrustGuard extension on managed Firefox."

<Note>
**Not in the catalog yet.** The browser collectors are not currently listed in
**Runtime → Collectors → Catalog**; the extension rollout flow is still being
finalised. Talk to us before planning around them.
</Note>

Deploy with Firefox enterprise policies (`policies.json`, GPO, or MDM).

1. Create an API key on the collector.
2. Force-install via `ExtensionSettings` using the ID from the collector panel.
3. Set policy endpoint and enrolled realm in extension prefs.
4. Confirm **Activity**.
