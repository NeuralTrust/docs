**Not in the catalog yet.** The browser collectors are not currently listed in

Chromium-based — same force-install pattern as Chrome, via Intune / Edge ADMX.

1. Create an API key on the collector.
2. Force-install the extension ID from the collector side panel.
3. Set policy endpoint and enrolled realm.
4. Assign the profile and confirm **Activity**.
