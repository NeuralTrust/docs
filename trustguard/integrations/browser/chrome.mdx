---
title: "Google Chrome"
description: "TrustGuard extension on managed Chrome."
---

<Note>
**Not in the catalog yet.** The browser collectors are not currently listed in
**Runtime → Collectors → Catalog**; the extension rollout flow is still being
finalised. Talk to us before planning around them.
</Note>

1. Create an API key on the collector (side panel has extension ID and policy endpoint).
2. Force-install the extension via Chrome enterprise policy or MDM.
3. Set policy endpoint = TrustGuard host, enrolled realm from the panel.
4. Confirm a test prompt in TrustGuard **Activity**.
