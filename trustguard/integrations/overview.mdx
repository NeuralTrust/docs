A [collector](/trustguard/concepts/collectors) is wherever you call
[`/v1/evaluate`](/trustguard/api/evaluate) (or `/v1/evaluate/claude`). The console
collector side panel has the steps and snippet for the integration you pick.

Except [TrustGate](/trustguard/integrations/gateway/trustgate) (native), integrations call:

```http
POST {TRUSTGUARD_URL}/v1/evaluate
Authorization: Bearer <collector API key>
Content-Type: application/json

{
  "protocol": "llm",
  "direction": "input",
  "payload": { "input": "…" },
  "session_id": "sess-123",
  "consumer_id": "alex@acme.com"
}
```

```text
block → deny · ask → IDE prompt · transform → forward transformed_payload · else → forward
```

Call with `direction: "input"` before the model and `"output"` after, unless TrustGate
owns the path. Full contract: [Evaluate API](/trustguard/api/evaluate).
