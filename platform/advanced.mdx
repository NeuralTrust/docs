Open **Platform settings → Advanced**. Owners and admins can edit **Data Plane Configuration**; other roles see a read-only view.

This page wires the **control plane** (SaaS) to your **data plane** after Helm is installed. SaaS-only teams normally skip it.

## Connect to existing

Use when the Hybrid chart is already running:

1. Enter the **Data Plane Endpoint** (`https://…`).
2. Enter the **JWT Secret** that matches the data-plane API.
3. **Save** and confirm.

<Warning>
Treat the JWT as a credential. Do not store it in source control.
</Warning>

This records the link on the team. It does not install Helm resources. DataAgent enrollment (`ENROLMENT_TOKEN` in Helm) is a separate step.

## Provision from the console

Optional AWS and GCP flows can create the Hybrid deployment for you. Azure UI provisioning is marked **coming soon** — deploy AKS with Helm, then use **Connect to existing**.

<Note>
Console provisioning and the [Infrastructure Helm guides](/neuraltrust/deployment/overview#provider-guides) are separate paths. If you install the chart yourself, finish with **Connect to existing** here.
</Note>

See [Deployment models](/neuraltrust/deployment/deployment-models) and [Secrets](/neuraltrust/deployment/secrets).
