## Prepare

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Install your ingress controller. Create the registry pull Secret and private PostgreSQL / Redis ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

## Prepare TrustGate

Use Kubernetes for production-grade deployments. Start a [private gateway](/neuraltrust/deployment/overview#create-a-private-trustgate-gateway), choose **Kubernetes**, and keep the wizard open. Treat the generated `values.yaml` as secret credential and setup input, not authoritative chart values. Choose **Manual** only for custom manifests; it displays `CONTROL_PLANE_JWT` and `DATA_AGENT_JWT`.

## Install

Deploy from the current maintained `neuraltrust-platform` chart or manifests. Review and map the wizard-generated credentials and settings into the maintained interfaces before applying; do not run the generated local-chart command unchanged. Move credentials into pre-created Kubernetes Secrets or an approved secret manager.

Configure the required storage class, Application Gateway or NGINX ingress, private PostgreSQL and Redis connectivity, registry access, DNS, and TLS. See [Configuration](/neuraltrust/deployment/configuration) and [Secrets](/neuraltrust/deployment/secrets).

Expose two ingress endpoints and verify DNS and TLS:

- LLM/proxy endpoint backed by a Service on port `80`, targeting TrustGate container port `8081`
- MCP endpoint backed by a Service on port `80`, targeting TrustGate container port `8082`

Return to the wizard, enter the LLM/proxy URL as the bootstrap **Dataplane URL**, and click **Save and Finish**. Then open **Settings → Agent Gateway → General** and set or verify the separate **LLM URL** and **MCP URL**.
