title: Hybrid
description: Install the Hybrid data plane on AKS.
---

## Prepare

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Install your ingress controller. Create the registry pull Secret and private PostgreSQL / Redis ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

## Values

```yaml
global:
  deploymentMode: hybrid
  platform: azure
  domain: platform.example.com
  storageClass: managed-csi-premium
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  postgresql:
    deploy: false
  redis:
    deploy: false
  ingress:
    className: azure-application-gateway
    azure:
      appGatewayName: neuraltrust-appgw
      sslCertificate: neuraltrust-tls
      sslRedirect: true
```

For NGINX, swap the ingress class/annotations. Complete store blocks per [Configuration](/neuraltrust/deployment/configuration).

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-aks-hybrid.yaml

kubectl get pods,ingress -n neuraltrust
```

Create DNS, verify TLS, then [Connect to existing](/platform/advanced#connect-to-existing).
