---

## Prepare

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Install your selected ingress controller and create the registry pull Secret or configure an internal image mirror.

## Values

Application Gateway example:

```yaml
global:
  deploymentMode: hybrid
  platform: azure
  domain: platform.example.com
  storageClass: managed-csi-premium
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  ingress:
    className: azure-application-gateway
    azure:
      appGatewayName: neuraltrust-appgw
      sslCertificate: neuraltrust-tls
      sslRedirect: true
```

For NGINX, replace the class and annotations with those of your installed controller. Configure private Azure PostgreSQL and Redis through the shared [managed-store values](/neuraltrust/deployment/configuration#managed-stores).

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --version 2.0.5 \
  --namespace neuraltrust \
  -f values-aks-hybrid.yaml

kubectl get pods,ingress -n neuraltrust
```

Create Azure DNS records after the ingress address is available, verify TLS, then use [Connect to existing](/platform/advanced#connect-to-existing).

## Verify

```bash
kubectl get ingress -n neuraltrust -o wide
kubectl describe ingress -n neuraltrust
kubectl get events -n neuraltrust --sort-by=.lastTimestamp
```

The Helm DataAgent enrollment token is optional and separate from the endpoint/JWT entered in the console.
