NeuralTrust supports AKS for Hybrid and External deployments.

## Cluster baseline

```bash
az aks create \
  --resource-group <RESOURCE_GROUP> \
  --name neuraltrust \
  --node-count 3 \
  --node-vm-size Standard_D8s_v5 \
  --enable-oidc-issuer \
  --enable-workload-identity \
  --generate-ssh-keys

az aks get-credentials \
  --resource-group <RESOURCE_GROUP> \
  --name neuraltrust
```

## Azure choices

- **Ingress:** Application Gateway Ingress Controller or an installed NGINX controller.
- **TLS:** an Application Gateway certificate, Key Vault integration, or cert-manager.
- **Storage:** `managed-csi` or `managed-csi-premium`.
- **Identity:** Microsoft Entra Workload ID instead of client secrets.
- **Datastores:** Azure Database for PostgreSQL Flexible Server and Azure Managed Redis through private endpoints.

When using Application Gateway, set `global.platform: azure`, the ingress class, and `global.ingress.azure.appGatewayName`/`sslCertificate`. For NGINX, use its class and cert-manager annotations instead.

## GPU workers

```bash
az aks nodepool add \
  --resource-group <RESOURCE_GROUP> \
  --cluster-name neuraltrust \
  --name firewallgpu \
  --node-vm-size Standard_NC4as_T4_v3 \
  --node-count 1 \
  --labels accelerator=nvidia \
  --node-taints nvidia.com/gpu=present:NoSchedule
```

Validate the NVIDIA device plugin and follow [Firewall GPU workers](/neuraltrust/deployment/firewall#gpu-workers).
