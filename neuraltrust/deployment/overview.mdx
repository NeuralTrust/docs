NeuralTrust supports **SaaS** and **Hybrid** deployments. SaaS is operated by NeuralTrust. Hybrid uses the `neuraltrust-platform` Helm chart with `global.deploymentMode: hybrid`.

## SaaS and Hybrid architecture

<img
  src="/images/static/img/platform-architecture.svg"
  alt="NeuralTrust SaaS and Hybrid architecture showing control and data planes, metadata export to ClickHouse Cloud, raw payload storage in customer PostgreSQL, and authorized retrieval through DataAgent and DataBridge."
/>

This simplified topology focuses on the primary request, telemetry, and retrieval paths. The Hybrid data-plane API is omitted.

In Hybrid, TrustGate proxy/MCP, TrustGuard runtime, Firewall, the data-plane API, and optionally DataAgent run in the customer cluster. Their control planes, the app/control-plane API, DataBridge, SaaS ClickStack collector, ClickHouse, and AlertEngine remain on NeuralTrust SaaS.

Hybrid exports **metadata only** over OTLP. Raw prompts and responses stay in the customer PostgreSQL, whether deployed in-cluster or provided as a managed service. DataAgent is enrollment-gated and performs authorized outbound retrieval from PostgreSQL through DataBridge when a user requests raw data. TrustGate and TrustGuard configuration sync is optional.

## Workload placement

| Workload | SaaS | Hybrid customer cluster |
| --- | --- | --- |
| TrustGate data plane (proxy/MCP), TrustGuard data plane | Hosted | Yes |
| TrustGate and TrustGuard control planes | Hosted | SaaS |
| Firewall | Hosted | Optional, default on |
| Data-plane API | Not deployed | Yes |
| DataAgent / SaaS DataBridge | N/A | Optional / SaaS |
| App and control-plane API | Hosted | SaaS |
| ClickStack collector, ClickHouse, DataCore, AlertEngine | Hosted | SaaS |
| PostgreSQL and Redis | Hosted | Shared local or managed stores |

## Install the chart

Start from the Hybrid example:

```bash
cp values-required.yaml values-hybrid.yaml

helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust --create-namespace \
  -f values-hybrid.yaml
```

Edit the copied file for the target environment. See [Secrets](/neuraltrust/deployment/secrets) and your [provider guide](#provider-guides) before installing.
