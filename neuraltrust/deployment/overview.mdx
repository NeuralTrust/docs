NeuralTrust supports **SaaS** and **Hybrid**. SaaS is fully operated by NeuralTrust. Hybrid runs the request-path **data plane** in your Kubernetes cluster and keeps the **control plane** on NeuralTrust SaaS.

## Architecture

<img
  src="/images/static/img/platform-architecture.svg"
  alt="NeuralTrust SaaS control plane connected to a customer Hybrid data plane: TrustGate and TrustGuard on the request path, metadata export to SaaS, raw payloads in customer PostgreSQL, and optional DataAgent retrieval."
/>

| Plane | Where it runs | What you care about |
| --- | --- | --- |
| **Control plane** | NeuralTrust SaaS | Console, configuration, analytics |
| **Data plane** | Your cluster (Hybrid) | TrustGate, TrustGuard, optional Firewall, data-plane API, optional DataAgent |

## How the planes connect

Hybrid needs a few outbound links from your cluster to SaaS. Raw prompts and responses stay in **your** PostgreSQL.

```text
 Your cluster (data plane)              NeuralTrust SaaS (control plane)
 ┌─────────────────────────┐            ┌────────────────────────────┐
 │ TrustGate  → TrustGuard │  metadata  │                            │
 │ (+ Firewall, optional)  │ ─────────▶ │  Console / analytics       │
 │                         │   (OTLP)   │                            │
 │ Data-plane API ◀───────────────────▶ │  Config / sync             │
 │ DataAgent (optional) ──────────────▶ │  Authorized retrieval      │
 └───────────┬─────────────┘            └────────────────────────────┘
             │
             ▼
    Your PostgreSQL + Redis
```

1. **Traffic path** — Clients hit TrustGate in your cluster; TrustGate calls TrustGuard (and Firewall when enabled) on the request path.
2. **Metadata** — Runtimes export metadata over OTLP to SaaS. Payloads are not exported.
3. **Control link** — After install, connect the data-plane API endpoint in [Platform settings → Advanced](/platform/advanced) so SaaS can sync and manage the deployment.
4. **Optional retrieval** — With DataAgent enrolled, SaaS can request specific raw records from your PostgreSQL through an authorized bridge.

PostgreSQL and Redis are **customer-managed** (not installed in the cluster). See [Configuration](/neuraltrust/deployment/configuration#managed-stores) for sizes.

## Install Hybrid

```bash
cp values-required.yaml values-hybrid.yaml

helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust --create-namespace \
  -f values-hybrid.yaml
```

Then follow [Configuration](/neuraltrust/deployment/configuration), [Secrets](/neuraltrust/deployment/secrets), and your [provider guide](#provider-guides).
