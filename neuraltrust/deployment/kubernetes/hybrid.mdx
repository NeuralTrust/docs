---
title: Hybrid
description: Install the Hybrid data plane on conformant Kubernetes.
---

## Prepare

```bash
kubectl create namespace neuraltrust
kubectl get storageclass
kubectl get ingressclass
```

Create the registry pull Secret, OTLP token Secret, TLS Secret (if needed), and managed PostgreSQL / Redis ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

## Values

```yaml
global:
  deploymentMode: hybrid
  platform: kubernetes
  domain: platform.example.com
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  postgresql:
    deploy: false
  redis:
    deploy: false
  ingress:
    className: nginx
    annotations:
      cert-manager.io/cluster-issuer: letsencrypt-prod
    tls:
      autoGenerate: false
      secretName: neuraltrust-tls

dataagent:
  tenantId: ""
  enrolmentToken: ""
```

Complete store blocks per [Configuration](/neuraltrust/deployment/configuration).

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-kubernetes-hybrid.yaml

kubectl get pods,ingress -n neuraltrust
```

Create DNS, verify TLS, then connect the data-plane endpoint in [Advanced](/platform/advanced#connect-to-existing).
