## Prepare

```bash
kubectl create namespace neuraltrust
kubectl get storageclass
kubectl get ingressclass
```

Create the registry pull Secret, OTLP token Secret, TLS Secret (if needed), and managed PostgreSQL / Redis ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

## Prepare TrustGate

Kubernetes is not a selectable runtime in the current TrustGate wizard. Start a [private gateway](/neuraltrust/deployment/overview#create-a-private-trustgate-gateway), choose **Manual**, and keep the wizard open. Manual displays only `CONTROL_PLANE_URL`, `CONTROL_PLANE_JWT`, `COLLECTOR_URL`, `COLLECTOR_JWT`, and `DATA_AGENT_JWT`; it does not generate manifests, values YAML, or a deployment command.

## Install

Deploy with your maintained Kubernetes manifests and inject the five Manual values through Secrets. Do not infer manifest or chart keys from the environment-variable names.

Configure the storage class, ingress controller, managed PostgreSQL and Redis connectivity, registry access, DNS, and TLS for your cluster. See [Configuration](/neuraltrust/deployment/configuration) and [Secrets](/neuraltrust/deployment/secrets).

Expose the TrustGate dataplane URL, create its DNS record, and verify TLS. Return to the still-open wizard, enter the **Dataplane URL**, and click **Save and Finish**.
