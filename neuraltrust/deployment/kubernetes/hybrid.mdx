---
title: Hybrid
description: Install Hybrid runtime workloads on conformant Kubernetes.
---

## Prepare

```bash
kubectl create namespace neuraltrust
kubectl get storageclass
kubectl get ingressclass
```

Create the NeuralTrust image pull Secret, the Hybrid ClickStack token Secret, and a trusted TLS Secret if your ingress controller does not provision certificates.

## Values

```yaml
global:
  deploymentMode: hybrid
  platform: kubernetes
  domain: platform.example.com
  storageClass: ""
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  ingress:
    className: nginx
    annotations:
      cert-manager.io/cluster-issuer: letsencrypt-prod
    tls:
      autoGenerate: false
      secretName: neuraltrust-tls

dataagent:
  tenantId: ""
  enrolmentToken: ""
```

Adapt ingress class, annotations, StorageClass, and TLS ownership to your distribution. Use [Configuration](/neuraltrust/deployment/configuration#managed-stores) for external PostgreSQL/Redis.

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-kubernetes-hybrid.yaml

kubectl get pods,service,ingress -n neuraltrust
```

Create DNS records for each rendered host and verify the certificate chain before connecting the endpoint in [Advanced](/platform/advanced#connect-to-existing).

## Verify

```bash
kubectl get events -n neuraltrust --sort-by=.lastTimestamp
kubectl describe ingress -n neuraltrust
kubectl get pvc -n neuraltrust
```

DataAgent is optional. It renders only after both tenant identity and a SaaS-issued enrollment token are configured.
