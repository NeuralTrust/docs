## Model comparison

| Model | Control plane | Runtime | Analytics | Helm setting |
| --- | --- | --- | --- | --- |
| **SaaS** | NeuralTrust SaaS | NeuralTrust SaaS | NeuralTrust SaaS | None |
| **Hybrid** | NeuralTrust SaaS | Your Kubernetes cluster | Metadata in SaaS ClickHouse; raw payloads in customer PostgreSQL | `global.deploymentMode: hybrid` |
| **External** | Your Kubernetes cluster | Your Kubernetes cluster | Local ClickHouse and PostgreSQL | `global.deploymentMode: external` |

Only **Hybrid** and **External** are Helm deployment modes. Do not set `global.deploymentMode: saas`.

## SaaS

NeuralTrust operates the app, APIs, TrustGate, TrustGuard, Firewall, databases, collector, and analytics. There is no chart to install.

## Hybrid

Hybrid keeps request-path workloads in your cluster while NeuralTrust operates their control planes and analytics services.

- TrustGate proxy/MCP and TrustGuard data plane run locally.
- Firewall is optional and enabled by default.
- The data-plane API runs locally.
- PostgreSQL and Redis are shared by the hybrid workloads; the chart can deploy them or connect to managed services.
- DataAgent renders only after `tenantId` and a SaaS-issued enrollment token are configured.
- Metadata is exported to SaaS ClickStack over OTLP. Raw prompts and responses remain in customer PostgreSQL.
- Authorized DataAgent/DataBridge reads can return requested local records to the SaaS application.

Raw payloads remain local except for records explicitly requested through authorized DataAgent/DataBridge retrieval.

## External

External is a supported self-hosted deployment mode. It adds:

- TrustGate and TrustGuard control planes.
- The web app and control-plane API.
- Local ClickStack OTel Collector and ClickHouse.
- DataCore for tenant-scoped residency queries.
- AlertEngine API and worker for local detection and alert state.

DataAgent is absent because no SaaS DataBridge is needed. Product telemetry is exported to the local ClickStack collector. External can use in-cluster or managed PostgreSQL, Redis, and ClickHouse; service databases and credentials must follow the [configuration](/neuraltrust/deployment/configuration) and [secrets](/neuraltrust/deployment/secrets) contracts.

## Connectivity

Hybrid requires outbound HTTPS for image pulls, SaaS configuration/enrollment, the DataBridge connection when DataAgent is enabled, and OTLP export when ClickStack is enabled. It also requires access to configured LLM upstreams. External has no required SaaS runtime dependency, but still needs registry and upstream access unless images and model endpoints are mirrored locally.

See the [architecture overview](/neuraltrust/deployment/overview) for complete workload placement.
