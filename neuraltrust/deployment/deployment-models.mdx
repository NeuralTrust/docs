## Comparison

| | **SaaS** | **Hybrid** |
| --- | --- | --- |
| Control plane | NeuralTrust | NeuralTrust |
| Data plane (TrustGate / TrustGuard) | NeuralTrust | Your Kubernetes cluster |
| Raw payloads | NeuralTrust | Your PostgreSQL |
| Metadata / analytics | NeuralTrust | Exported to NeuralTrust (OTLP) |
| Helm | None | `global.deploymentMode: hybrid` |

Only **Hybrid** uses the Platform chart. Do not set `global.deploymentMode: saas`.

## SaaS

NeuralTrust operates both planes. There is nothing to install in your cluster.

## Hybrid

You run the data plane; NeuralTrust runs the control plane.

**In your cluster:** TrustGate, TrustGuard, optional Firewall, data-plane API, and optionally DataAgent — plus connectivity to **your** PostgreSQL and Redis.

**On NeuralTrust SaaS:** the console and control plane that configure and observe that data plane.

**Between the planes:**

- Outbound OTLP for metadata (payloads stay local)
- Data-plane API linked from the console ([Advanced](/platform/advanced))
- Optional DataAgent enrollment for authorized raw-record retrieval

See [Overview](/neuraltrust/deployment/overview) for the connection diagram and [Configuration](/neuraltrust/deployment/configuration) for chart values and store sizes.

## Connectivity checklist

From the Hybrid cluster you need outbound HTTPS to:

- The container registry (or your mirror)
- NeuralTrust SaaS (metadata export, enrollment / sync)
- Your LLM upstreams
- Your managed PostgreSQL and Redis
