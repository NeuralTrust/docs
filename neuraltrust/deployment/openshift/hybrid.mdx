## Values

Copy chart `values-openshift.yaml` and add the Hybrid OTLP Secret reference:

```yaml
global:
  deploymentMode: hybrid
  platform: openshift
  domain: apps.example.com
  imageRegistry: ""
  storageClass: ""
  autoGenerateSecrets: true
  preserveExistingSecrets: false
  security:
    allowInsecureImages: true
  ingress:
    provider: openshift
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS

dataagent:
  tenantId: ""
  enrolmentToken: ""
```

Create `clickstack-otlp-token` and the registry pull Secret before installation. See [Secrets](/neuraltrust/deployment/secrets).

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-openshift-hybrid.yaml

oc get pods,route -n neuraltrust
```

If component service accounts cannot pull images, link `gcr-secret` to the affected service account with `oc secrets link <service-account> gcr-secret --for=pull`.

## DNS and TLS

Inspect Route hosts:

```bash
oc get route -n neuraltrust
oc describe route -n neuraltrust
```

When hosts are under the cluster wildcard, the router DNS and wildcard certificate may already cover them. For custom hosts, configure DNS and Route TLS according to the cluster ingress policy.

## Verify security constraints

```bash
oc get events -n neuraltrust --sort-by=.lastTimestamp
oc get scc
```

Do not grant broad privileged SCC access as a generic fix. GPU workers may need a purpose-built SCC because their example uses `hostIPC`.

After TLS is ready, connect the endpoint in [Advanced](/platform/advanced#connect-to-existing).
