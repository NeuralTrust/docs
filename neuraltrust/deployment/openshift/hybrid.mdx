## Values

Start from `values-openshift.yaml`:

```yaml
global:
  deploymentMode: hybrid
  platform: openshift
  domain: apps.example.com
  ingress:
    provider: openshift
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  postgresql:
    deploy: false
  redis:
    deploy: false

dataagent:
  tenantId: ""
  enrolmentToken: ""
```

Create `clickstack-otlp-token`, the registry Secret, and your managed stores ([Configuration](/neuraltrust/deployment/configuration), [Secrets](/neuraltrust/deployment/secrets)).

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-openshift-hybrid.yaml

oc get pods,route -n neuraltrust
```

Link `gcr-secret` to service accounts that need pull access if pods fail image pulls.

## DNS and TLS

```bash
oc get route -n neuraltrust
```

Cluster wildcard DNS/certs may already cover Route hosts. For custom hosts, follow cluster ingress policy. Then connect the data-plane endpoint in [Advanced](/platform/advanced#connect-to-existing).
