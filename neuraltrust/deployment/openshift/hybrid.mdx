## Prepare TrustGate

OpenShift is not a selectable runtime in the current TrustGate wizard. Start a [private gateway](/neuraltrust/deployment/overview#create-a-private-trustgate-gateway), choose **Manual**, and keep the wizard open. Manual displays only `CONTROL_PLANE_URL`, `CONTROL_PLANE_JWT`, `COLLECTOR_URL`, `COLLECTOR_JWT`, and `DATA_AGENT_JWT`; it does not generate manifests, values YAML, or a deployment command.

## Install

Deploy with your maintained OpenShift manifests and inject the five Manual values through Secrets. Do not infer manifest or chart keys from the environment-variable names.

Configure Routes or ingress, managed PostgreSQL and Redis connectivity, registry access, DNS, and TLS. Link the registry Secret to service accounts that need pull access. See [Configuration](/neuraltrust/deployment/configuration) and [Secrets](/neuraltrust/deployment/secrets).

## DNS and TLS

```bash
oc get route -n neuraltrust
```

Cluster wildcard DNS/certificates may already cover Route hosts. For custom hosts, follow cluster ingress policy. Expose the TrustGate dataplane URL, then return to the still-open wizard, enter the **Dataplane URL**, and click **Save and Finish**.
