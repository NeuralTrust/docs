title: Hybrid
description: Install the Hybrid data plane on EKS.
---

## Prepare

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Install EBS CSI and the AWS Load Balancer Controller. Create the registry pull Secret ([Images](/neuraltrust/deployment/images)) and private RDS / ElastiCache ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

## Values

```yaml
global:
  deploymentMode: hybrid
  platform: aws
  domain: platform.example.com
  storageClass: gp3
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  postgresql:
    deploy: false
  redis:
    deploy: false
  ingress:
    className: alb
    aws:
      scheme: internet-facing
      targetType: ip
      certificateArn: arn:aws:acm:<REGION>:<ACCOUNT_ID>:certificate/<ID>
```

Complete store blocks per [Configuration](/neuraltrust/deployment/configuration). Prefer IRSA where the chart supports IAM auth.

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-eks-hybrid.yaml

kubectl get pods,ingress -n neuraltrust
```

Point DNS at the ALB, then connect the data-plane endpoint in [Advanced](/platform/advanced).
