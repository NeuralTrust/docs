Use Amazon EKS for the Hybrid **data plane**. The control plane stays on NeuralTrust SaaS — see [Overview](/neuraltrust/deployment/overview).

## Cluster baseline

Defaults are a comfortable starting point for Hybrid (**3–4** × `m6i.2xlarge`).
External usually wants **one extra node**. Right-size later — see
[Cluster sizing](/neuraltrust/deployment/sizing).

```bash
eksctl create cluster \
  --name neuraltrust \
  --region <REGION> \
  --managed \
  --node-type m6i.2xlarge \
  --nodes 3

aws eks update-kubeconfig \
  --name neuraltrust \
  --region <REGION>
```

Install the EBS CSI driver and the AWS Load Balancer Controller for ALB ingress. Use IRSA for AWS API access.

## AWS choices

- **Ingress / TLS:** ALB (`global.ingress.className: alb`) + ACM (`certificateArn`)
- **Datastores:** private RDS/Aurora and ElastiCache — [minimum sizes](/neuraltrust/deployment/configuration#managed-stores)
- **Network:** [Hybrid network allowlist](/neuraltrust/deployment/network) (config-sync / DataBridge egress + NeuralTrust inbound source IP); also registry, LLM upstreams, your stores

<Note>
On RDS with IAM authentication, `global.postgresql.authMode: iam` does not reach the Go gateways in external mode. Also set `agentgateway.database.iamAuth: true` and `trustguard.database.iamAuth: true`, or they attempt password authentication against an IAM-only database and fail at connection time.
</Note>

## GPU workers (optional)

Only if you run Firewall on GPU — see [Firewall](/neuraltrust/deployment/firewall#gpu-workers).

## Install

Once the cluster exists, verify it and create the namespace:

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Create the registry pull Secret ([Images](/neuraltrust/deployment/images)) and your private RDS / ElastiCache instances, then follow the shared install sequence — Secrets, values file, `helm upgrade --install`, verification — which is the same on every provider:

- [Quick start](/neuraltrust/deployment/quickstart) for the commands
- [Hybrid walkthrough](/neuraltrust/deployment/hybrid-walkthrough) for the reasoning behind each step and what to check when it goes wrong
