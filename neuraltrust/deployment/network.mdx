---
title: Hybrid network allowlist
description: Hostnames and IPs your Hybrid cluster must allow for config-sync, DataBridge, and NeuralTrust inbound traffic.
---

Hybrid data planes open **outbound** connections to NeuralTrust for
configuration sync and DataBridge. Your firewall or security-group rules must
allow the destinations below from cluster worker nodes (and from any egress
NAT or proxy in front of them).

Prefer **hostname** rules when your firewall supports DNS-based allowlists.
The IPs below are for static ACLs. If DNS resolves differently in your region,
trust DNS and contact NeuralTrust support to refresh the IP list.

## Outbound (egress)

Allow **TCP 443** from your cluster egress to:

| Hostname | IP | Purpose |
| --- | --- | --- |
| `agentgateway-configsync.neuraltrust.ai` | `34.22.134.169` | TrustGate (AgentGateway) config-sync |
| `trustguard-configsync.neuraltrust.ai` | `34.62.69.111` | TrustGuard config-sync |
| `databridge.neuraltrust.ai` | `34.62.63.231` | DataAgent DataBridge |
| `telemetry.neuraltrust.ai` | resolve via DNS | Product metadata OTLP export (EU) |
| `telemetry.us.neuraltrust.ai` | resolve via DNS | Product metadata OTLP export (US) |

Product metadata OTLP does not leave the pods directly: a co-located egress
collector forwards to the ingest edge for your region, so that is the host to
allow if your policy lists every external destination. Allow the one matching
the region your tenant is provisioned in.

Also allow outbound HTTPS to your container registry (or mirror), LLM
upstreams, and managed PostgreSQL / Redis.

## Inbound (ingress)

Hybrid is not egress-only. The **Dataplane URL** you register in the console is
a URL NeuralTrust calls, so your published TrustGate LLM and MCP entry points
must accept inbound HTTPS from this source IP:

| Source IP |
| --- |
| `34.78.98.144` |

Scope the rule to your edge or ingress for those two hosts. Config-sync and
DataBridge are **outbound-only** — you do not open inbound ports for those
services, and nothing needs to reach TrustGuard, Firewall or DataAgent from
outside the cluster.
