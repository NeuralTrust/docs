title: Feature flags reference
description: Chart switches that change the Hybrid data plane.
---

| Value | Hybrid guidance | Effect |
| --- | --- | --- |
| `global.deploymentMode` | `hybrid` | Required. Renders the data plane. |
| `global.postgresql.deploy` | **`false`** | Use your managed PostgreSQL. |
| `global.redis.deploy` | **`false`** | Use your managed Redis. |
| `global.clickstack.enabled` | `true` | Metadata export to SaaS (OTLP). |
| `agentgateway.mcp.enabled` | `true` | TrustGate MCP (chart key `agentgateway`). |
| `agentgateway.configSync.enabled` | Docker enables it; operators configure it | Outbound TrustGate configuration sync (chart key `agentgateway`). |
| `trustguard.configSync.enabled` | Separately provisioned credential required | Outbound TrustGuard configuration sync. |
| `firewall.enabled` / `firewall.firewall.enabled` / `trustguard.firewall.enabled` | Keep aligned | Optional Firewall with TrustGuard. |
| `global.autoGenerateSecrets` | `true` | Chart-owned secrets when values are empty. |
| `global.preserveExistingSecrets` | `false` | GitOps: pre-create secrets and set `true`. |

Leave `trustlens.enabled` and `watchdog.enabled` off unless NeuralTrust asks you to enable them.

The private TrustGate wizard's Docker command supplies the TrustGate configuration-sync token and endpoint. The wizard does not issue a TrustGuard configuration-sync credential; that requires a separately provisioned TrustGuard instance and credential.

For operator-managed Kubernetes, choose **Manual** in the wizard to obtain its five environment values and use maintained manifests. The Manual creation path does not generate chart values; after setup, **Settings → Agent Gateway → Deployment** can regenerate `values.yaml` for the gateway.

## Managed stores (required)

```yaml
global:
  deploymentMode: hybrid
  postgresql:
    deploy: false
    host: postgres.example.com
    port: 5432
    user: neuraltrust
    database: neuraltrust
    sslMode: require
    existingSecret:
      name: hybrid-postgresql
  redis:
    deploy: false
    host: redis.example.com
    port: 6379
    tls: "true"
    existingSecret:
      name: hybrid-redis
```

Sizes: [Configuration](/neuraltrust/deployment/configuration#managed-stores).

## Platform and routing

`global.platform`: `aws` · `gcp` · `azure` · `openshift` · `kubernetes`.  
`global.domain` drives chart ingress names only. The console's LLM and MCP hosts derive from the finalized Dataplane URL. Ingress class/annotations are provider-specific. `global.imageRegistry` rewrites the registry prefix for mirrors.

See [Configuration](/neuraltrust/deployment/configuration) and [Secrets](/neuraltrust/deployment/secrets).
