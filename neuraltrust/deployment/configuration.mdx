Canonical chart inputs:

```bash
cp values-required.yaml values-hybrid.yaml
```

## Minimal Hybrid

Set `deploymentMode: hybrid`, point at **your** PostgreSQL and Redis (`deploy: false`), and provide the SaaS OTLP token for metadata export.

```yaml
global:
  deploymentMode: hybrid
  platform: kubernetes
  domain: platform.example.com
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  postgresql:
    deploy: false
    host: postgres.example.com
    port: 5432
    user: neuraltrust
    database: neuraltrust
    sslMode: require
    existingSecret:
      name: hybrid-postgresql
  redis:
    deploy: false
    host: redis.example.com
    port: 6379
    tls: "true"
    existingSecret:
      name: hybrid-redis

dataagent:
  tenantId: ""
  enrolmentToken: ""
```

DataAgent stays off until `tenantId` and an enrollment token (or Secret) are set. After install, connect the data-plane endpoint in [Platform settings → Advanced](/platform/advanced).

## Managed stores

Do not run PostgreSQL or Redis in the cluster. Pre-create one shared database/role and Redis; Helm does not create managed-service users.

| Store | Minimum size |
| --- | --- |
| **PostgreSQL** | **2 vCPU**, **4 GiB RAM**, **20 GiB** storage |
| **Redis** | **1 GiB** memory |

| Provider | PostgreSQL | Redis |
| --- | --- | --- |
| AWS | RDS/Aurora `db.t4g.medium`, 20 GiB+ | ElastiCache `cache.t4g.small` |
| GCP | Cloud SQL `db-custom-2-4096`, 20 GiB+ | Memorystore **1 GiB** |
| Azure | Flexible Server **2 vCores / 4 GiB**, 20 GiB+ | Cache for Redis **C1** (1 GiB)+ |

Reach both over private networking from the cluster. Secret key contracts: [Secrets](/neuraltrust/deployment/secrets).

## Ingress

```yaml
global:
  platform: aws
  domain: platform.example.com
  storageClass: gp3
  ingress:
    className: alb
    aws:
      certificateArn: arn:aws:acm:region:account:certificate/id
```

Hosts are derived from `global.domain`. Cluster storage is only for optional chart components — not for PostgreSQL or Redis.
