title: Hybrid
description: Install Hybrid runtime workloads on GKE.
---

## Prepare

Confirm the cluster has a default StorageClass and an ingress path:

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Create the registry pull Secret supplied by NeuralTrust, or configure your mirror as described in [Images](/neuraltrust/deployment/images).

## Values

Copy chart `values-required.yaml`, then set GCP routing:

```yaml
global:
  deploymentMode: hybrid
  platform: gcp
  domain: platform.example.com
  storageClass: premium-rwo
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  ingress:
    gcp:
      staticIpName: neuraltrust-ip
      managedCertificates: neuraltrust-cert
```

Pre-create `clickstack-otlp-token`; see [Secrets](/neuraltrust/deployment/secrets). For Cloud SQL or Memorystore, use the shared Hybrid blocks in [Configuration](/neuraltrust/deployment/configuration#managed-stores) and private connectivity.

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-gke-hybrid.yaml

kubectl get pods,ingress -n neuraltrust
```

Create DNS records for the rendered hosts after the GKE load-balancer address is assigned. Wait for managed certificates to become active before connecting the endpoint in [Platform settings → Advanced](/platform/advanced).

## Verify

```bash
kubectl get ingress -n neuraltrust -o wide
kubectl get managedcertificate -n neuraltrust
kubectl get events -n neuraltrust --sort-by=.lastTimestamp
```

DataAgent is optional and remains absent unless its tenant and enrollment Secret are configured.
