## Prepare

```bash
kubectl get nodes
kubectl get storageclass
kubectl create namespace neuraltrust
```

Create the registry pull Secret ([Images](/neuraltrust/deployment/images)) and your Cloud SQL / Memorystore instances ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

## Values

```yaml
global:
  deploymentMode: hybrid
  platform: gcp
  domain: platform.example.com
  storageClass: premium-rwo
  clickstack:
    existingSecret:
      name: clickstack-otlp-token
      key: OTEL_EXPORTER_OTLP_HEADERS
  postgresql:
    deploy: false
    # host + existingSecret → see Configuration
  redis:
    deploy: false
  ingress:
    gcp:
      staticIpName: neuraltrust-ip
      managedCertificates: neuraltrust-cert
```

Complete PostgreSQL/Redis blocks and secrets per [Configuration](/neuraltrust/deployment/configuration) and [Secrets](/neuraltrust/deployment/secrets).

## Install

```bash
helm upgrade --install neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-gke-hybrid.yaml

kubectl get pods,ingress -n neuraltrust
```

Point DNS at the load balancer, wait for certificates, then connect the data-plane endpoint in [Platform settings → Advanced](/platform/advanced).
