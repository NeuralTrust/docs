NeuralTrust supports GKE Standard clusters for Hybrid and External deployments. Read [Deployment models](/neuraltrust/deployment/deployment-models) before selecting the chart mode.

## Cluster baseline

```bash
gcloud container clusters create neuraltrust \
  --region <REGION> \
  --release-channel regular \
  --workload-pool=<PROJECT_ID>.svc.id.goog \
  --machine-type e2-standard-8 \
  --num-nodes 1

gcloud container clusters get-credentials neuraltrust \
  --region <REGION> \
  --project <PROJECT_ID>
```

Size nodes from rendered requests and your availability policy. Use regional node pools for production.

## GCP choices

- **Ingress:** GKE Ingress with a reserved global address, or an installed NGINX/Gateway API controller.
- **TLS:** Google-managed certificates or cert-manager.
- **Storage:** `standard-rwo` or `premium-rwo`; set `global.storageClass`.
- **Identity:** Workload Identity Federation for GKE instead of static cloud keys.
- **Datastores:** Cloud SQL private IP and Memorystore are supported through the central managed-store values.

For GKE Ingress, set `global.platform: gcp`, configure `global.ingress.gcp.staticIpName` and `managedCertificates`, and ensure DNS points to the reserved address.

## GPU workers

```bash
gcloud container node-pools create firewall-gpu \
  --cluster neuraltrust \
  --region <REGION> \
  --machine-type n1-standard-4 \
  --accelerator type=nvidia-tesla-t4,count=1 \
  --num-nodes 1 \
  --node-labels accelerator=nvidia \
  --node-taints nvidia.com/gpu=present:NoSchedule
```

Install the NVIDIA driver/device-plugin path supported by your GKE version, then apply the [Firewall GPU overlay](/neuraltrust/deployment/firewall#gpu-workers).

Continue with [GKE Hybrid](/neuraltrust/deployment/gcp/hybrid), or use the [External configuration](/neuraltrust/deployment/configuration#minimal-external).
