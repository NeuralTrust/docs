Use GKE Standard for the Hybrid **data plane**. The control plane stays on NeuralTrust SaaS — see [Overview](/neuraltrust/deployment/overview).

## Cluster baseline

Defaults are a comfortable starting point for Hybrid (`e2-standard-8` in a
regional cluster — typically **3** zones × 1 node). External usually wants
**one extra node**. Right-size later — see
[Cluster sizing](/neuraltrust/deployment/sizing).

```bash
gcloud container clusters create neuraltrust \
  --region <REGION> \
  --release-channel regular \
  --workload-pool=<PROJECT_ID>.svc.id.goog \
  --machine-type e2-standard-8 \
  --num-nodes 1

gcloud container clusters get-credentials neuraltrust \
  --region <REGION> \
  --project <PROJECT_ID>
```

## GCP choices

- **Ingress / TLS:** GKE Ingress + reserved address, or NGINX/Gateway API; Google-managed certs or cert-manager
- **Identity:** Workload Identity Federation
- **Datastores:** Cloud SQL (private IP) and Memorystore — [minimum sizes](/neuraltrust/deployment/configuration#managed-stores)
- **Network:** [Hybrid network allowlist](/neuraltrust/deployment/network) (config-sync / DataBridge egress + NeuralTrust inbound source IP); also registry, LLM upstreams, your stores

For GKE Ingress set `global.platform: gcp`, `global.ingress.gcp.staticIpName`, and `managedCertificates`.

## GPU workers (optional)

Only if you run Firewall on GPU — see [Firewall](/neuraltrust/deployment/firewall#gpu-workers).
