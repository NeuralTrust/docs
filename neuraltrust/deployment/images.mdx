---
title: Image catalog
description: Container images for the Hybrid data plane.
---

Hybrid pulls these images into **your** cluster. The control plane stays on NeuralTrust SaaS and is not installed from this chart.

PostgreSQL and Redis are not chart images — use your own managed instances ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

Registry default: `europe-west1-docker.pkg.dev/neuraltrust-app-prod/nt-docker`. Confirm exact paths with `helm template`.

| Image | Tag | Notes |
| --- | --- | --- |
| TrustGate | `v0.13.0` | Data-plane gateway |
| TrustGuard | `v0.15.0` | Data-plane runtime |
| Firewall (CPU) | `v2.14.0` | Optional, default on |
| Data-plane API | `v1.42.0` | Control-plane link from the console |
| DataAgent | `v0.3.0` | Optional; enrolled Hybrid only |

Optional platform helpers (off unless enabled): OpenTelemetry Collector Contrib `0.153.0`, Watchdog `v0.13.1`, Prometheus `v3.12.0`.

## Mirror images

```yaml
global:
  imageRegistry: registry.example.com/neuraltrust
  imagePullSecrets:
    - name: neuraltrust-registry
```

```bash
cp values-required.yaml values-hybrid.yaml

helm template neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-hybrid.yaml
```

Keep tags aligned with the current chart unless NeuralTrust provides a tested matrix. GPU Firewall needs a separate image — see [Firewall](/neuraltrust/deployment/firewall).
