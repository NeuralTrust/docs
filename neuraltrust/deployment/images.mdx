Hybrid pulls runtime images into **your** environment. The control plane stays on NeuralTrust SaaS.

PostgreSQL and Redis are not chart images — use your own managed instances ([sizes](/neuraltrust/deployment/configuration#managed-stores)).

The visible wizard does not show image paths or tags:

- **Docker** fetches the maintained TrustGate Compose manifest, which selects the runtime images.
- **Operator-managed Kubernetes or OpenShift** uses maintained manifests or charts; those manifests are the source of image repositories and versions.

Mirror every image referenced by your maintained manifest, including enabled TrustGuard, Firewall, DataAgent, and telemetry components.

## Mirror images

```yaml
global:
  imageRegistry: registry.example.com/neuraltrust
  imagePullSecrets:
    - name: neuraltrust-registry
```

If you mirror images, rewrite only the registry location and preserve the repository names and tags pinned by your maintained manifest. GPU Firewall needs a separate image — see [Firewall](/neuraltrust/deployment/firewall).
