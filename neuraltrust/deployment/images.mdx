## Mirror images

Set one registry prefix when your mirror preserves image names and tags:

```yaml
global:
  imageRegistry: registry.example.com/neuraltrust
  imagePullSecrets:
    - name: neuraltrust-registry
```

Render the Hybrid topology before mirroring so you only pull the images your values enable:

```bash
cp values-required.yaml values-hybrid.yaml

helm template neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --namespace neuraltrust \
  -f values-hybrid.yaml
```

Per-component `image.repository`, `image.tag`, and `image.pullPolicy` values override defaults. Keep image tags aligned with the current chart unless NeuralTrust provides a tested release matrix.

The current Firewall chart uses the CPU image for its gateway and workers. GPU scheduling alone does not substitute a GPU image; see [Firewall](/neuraltrust/deployment/firewall).
