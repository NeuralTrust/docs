## Mirror images

Set one registry prefix when your mirror preserves image names and tags:

```yaml
global:
  imageRegistry: registry.example.com/neuraltrust
  imagePullSecrets:
    - name: neuraltrust-registry
```

Render the exact topology before mirroring because Hybrid and External use different subsets:

```bash
cp values-v2-hybrid.yaml.example values-v2-hybrid.yaml

helm template neuraltrust-platform \
  oci://europe-west1-docker.pkg.dev/neuraltrust-app-prod/helm-charts/neuraltrust-platform \
  --version 2.0.5 \
  --namespace neuraltrust \
  -f values-v2-hybrid.yaml
```

Per-component `image.repository`, `image.tag`, and `image.pullPolicy` values override defaults. Keep image tags aligned with chart 2.0.5 unless NeuralTrust provides a tested compatibility matrix.

Firewall chart 2.0.5 uses the CPU image for its gateway and workers. GPU scheduling alone does not substitute a GPU image; see [Firewall](/neuraltrust/deployment/firewall).
