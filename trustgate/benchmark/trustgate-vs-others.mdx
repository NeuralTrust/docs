To ensure an objective and reliable comparison, we conducted benchmark tests on multiple API gateways using **Google Cloud Platform (GCP) Compute Engine**. Each gateway was deployed on two machine types to evaluate how they perform under different hardware constraints:

- **c2-standard-8**: 8 vCPUs, 32 GB Memory
- **c4-highcpu-8**: 8 vCPUs, 16 GB Memory

Each gateway was the only process running on its test machine, ensuring isolated, consistent conditions. We used the [`hey`](https://github.com/rakyll/hey) HTTP load testing tool to simulate **50 concurrent users over a 30-second period**, measuring:

- **Requests per second (throughput)**
- **Average response time (latency in milliseconds)**
