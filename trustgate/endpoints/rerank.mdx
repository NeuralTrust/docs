---

Rerank accepts the Cohere v2 request and response format:

```text
/{consumer_slug}/v1/rerank
```

## Endpoint

| Method | Path after consumer slug | Client format |
|---|---|---|
| `POST` | `/v1/rerank` | Cohere Rerank v2 |

## Send a request

```bash
curl -X POST "https://<llm-host>/<consumer-slug>/v1/rerank" \
  -H "X-AG-API-Key: <consumer-api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "rerank-v3.5",
    "query": "What is a zero-trust gateway?",
    "documents": [
      "A gateway that verifies every request and applies policy.",
      "A network device that trusts all internal traffic."
    ],
    "top_n": 2
  }'
```

The provider response is returned in Cohere rerank format with relevance scores and document
indexes.

## Registry support

Rerank currently requires a **Cohere** registry. TrustGate excludes other providers from
the routing pool for this endpoint. A qualified request that explicitly selects an
incompatible provider returns `400 invalid_request`. If the consumer has no compatible
Cohere registry in its pool, TrustGate returns `503 no_backend_available`.

## Limitations

- This is a Cohere-compatible endpoint, not an OpenAI endpoint.
- Rerank does not support streaming.
- Consumer model allowlists and defaults apply.
- Unknown endpoint shapes return **404**.

Copy the host and credentials from the consumer **Connect** tab. See
[Auth](/trustgate/concepts/auth).
