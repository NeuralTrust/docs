The Developers section is the low-level reference for teams that operate the TrustGate Runtime directly — configuring the gateway, writing rules, extending plugins, wiring observability, and hitting the Actions API.

If you're designing policies, security capabilities, or enforcement in the platform UI, the [Runtime by TrustGate](/trustgate/platform) docs are the right starting point. The pages linked below go one layer deeper, into the runtime primitives those platform features are built on.
