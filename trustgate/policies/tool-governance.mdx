---
title: "Tool governance"
description: "Control agent tools at the gateway — allowlists, call validation, schema transforms, injection, and per-tool rate limits from the Policies catalog."
---

For agent and function-calling traffic, TrustGate can govern **tools** with several catalog
policies. Create them under **Policies** → **Catalog**, or attach them from a consumer
**Policies** tab. Scope each policy **gateway-wide** or **targeted**.

| Policy (`slug`) | What it does |
|---|---|
| [`tool_allowlist`](#tool-allowlist) | Allow or deny tools in the request `tools[]` array. |
| [`tool_call_validation`](#tool-call-validation) | Validate / redact tool calls the model returns. |
| [`tool_definition_transformation`](#tool-definition-transformation) | Patch schemas, override descriptions, inject tools. |
| [`per_tool_rate_limiter`](#per-tool-rate-limiter) | Rate-limit individual tool names/patterns. |

MCP tool **grants** on consumers/roles (which MCP tools an agent may see) are separate —
configure those on the consumer or [role](/trustgate/concepts/roles), and see
[MCP](/trustgate/mcp/overview).

---

## Tool allowlist

**`tool_allowlist`** — allow or deny patterns for tools the client sends.

Configure in the UI: allow/deny lists, empty-list behavior (reject all vs allow all), and
match patterns for tool names.

---

## Tool call validation

**`tool_call_validation`** — inspect tool calls in the model response.

UI validators can include:

| Validator | Use |
|---|---|
| Allowlist | Only named tools may be called. |
| JSON schema | Arguments must match a schema. |
| Semantic | Embedding/similarity checks on arguments. |
| Regex | Pattern match on name or arguments. |
| Denylist | Block specific tools or argument shapes. |

Choose enforce vs observe on the policy **Scope** section.

---

## Tool definition transformation

**`tool_definition_transformation`** — rewrite the tool definitions the model sees.

| Capability | Meaning |
|---|---|
| Schema / description patches | Override provider tool metadata. |
| Inject tools | Add operator-authored function tools (similar to legacy “tool injection”). |
| Conflict rules | What happens when an injected name collides with the client’s tools. |

---

## Per-tool rate limiter

**`per_tool_rate_limiter`** — limit how often a tool pattern may run.

| Setting (UI) | Meaning |
|---|---|
| Tool patterns | Names or globs to match. |
| Window + max | Requests (or calls) per window. |
| On exceed | Reject, inject an error tool result, or strip the tool call. |
