---
title: NeuralTrust Content Moderation
---

NeuralTrust Guardrail includes semantic similarity-based content moderation capabilities as part of its defense system. This feature is designed to identify and block content that matches predefined samples, providing a flexible way to moderate content based on semantic similarity rather than exact keyword matching.

## Content Moderation

The NeuralTrust content moderation system uses embedding-based semantic similarity to detect content that is similar to predefined deny samples. This approach allows for more nuanced content moderation compared to simple keyword matching, as it can detect content with similar meaning even when different words are used.

## Configuration

The moderation feature can be configured in the NeuralTrust Guardrail plugin:

```json
{
    "name": "neuraltrust_guardrail",
    "enabled": true,
    "stage": "pre_request",
    "priority": 1,
    "settings": {
        "credentials": {
            "token": "{{ NEURALTRUST_API_KEY }}",
            "base_url": "https://data.neuraltrust.ai"
        },
        "moderation":{
            "enabled": true,
            "threshold": 0.8,
            "deny_topic_action": "block",
            "deny_samples": [
                "This is an example of content that should be blocked",
                "Another example of prohibited content"
            ],
            "embedding_config": {
                "provider": "openai",
                "model": "text-embedding-ada-002",
                "credentials": {
                    "header_name": "Authorization",
                    "header_value": "Bearer {{ OPENAI_API_KEY }}"
                }
            }
        }
    }
}
```

### Configuration Parameters

| Parameter                                  | Type    | Description                                                                | Required | Default |
|--------------------------------------------|---------|----------------------------------------------------------------------------|----------|---------|
| `moderation`                               | object  | Enables or disables semantic similarity-based content moderation.          | No       | —       |
| `moderation.enabled`                       | boolean | Whether to enable the moderation check.                                    | No       | false   |
| `moderation.threshold`                     | float   | Threshold between `0.0` and `1.0` to flag the input.                       | No       | 0       |
| `moderation.deny_topic_action`             | string  | Action to take when content matches deny samples (only "block" supported). | No       | —       |
| `moderation.deny_samples`                  | array   | List of text samples to block (semantic similarity comparison).            | No       | []      |
| `moderation.embedding_config`              | object  | Configuration for the embedding service used for similarity detection.     | No       | —       |
| `moderation.embedding_config.provider`     | string  | Embedding provider (currently only "openai" supported).                    | No       | —       |
| `moderation.embedding_config.model`        | string  | Model to use for generating embeddings.                                    | No       | —       |
| `moderation.embedding_config.credentials`  | object  | Credentials for the embedding service.                                     | No       | —       |

## Error Responses

When moderated content is detected, the plugin returns a 403 Forbidden error:

```json
{
  "error": "content blocked: with similarity score 0.85 exceeds threshold 0.80",
  "retry_after": null
}
```
