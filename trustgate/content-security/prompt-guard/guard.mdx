# Hacker Prompts Detection System

This document introduces the Prompt Guard plugin for TrustGate — a robust detection layer that proactively filters malicious or adversarial prompts targeting Large Language Models (LLMs). Built for real-time gateway enforcement, Prompt Guard intercepts unsafe instructions before they reach the underlying model.

The plugin leverages SetFit (Sentence Transformers Fine-tuning) combined with optimized multilingual embeddings to detect jailbreaks, prompt injections, and code manipulation attempts. It is integrated directly into the AI gateway at the pre-request stage, enabling low-latency, multilingual protection.

Prompt Guard supports various embedding backends to meet different latency and resource profiles, and includes specialized models for code injection, offensive language, and adversarial manipulation patterns.

## Introduction

SetFit (Sentence Transformers Fine-tuning) is an efficient and prompt-free framework for few-shot fine-tuning of Sentence Transformers. It achieves high accuracy with minimal labeled data, making it competitive with larger models like RoBERTa Large. Unlike traditional few-shot learning methods, SetFit does not require handcrafted prompts or verbalizers, instead generating rich embeddings directly from text examples. This results in faster training and inference times compared to large-scale models such as T0 or GPT-4. SetFit’s compatibility with any Sentence Transformer on the Hugging Face Hub allows for multilingual classification, making it versatile for global applications.

In our efforts to enhance the detection capabilities of the Hacker Prompts Firewall, we tested different approaches by varying the text embeddings. This experimentation aimed to improve model metrics and ensure robust performance across diverse and evolving hacker prompt scenarios.

## Dataset

The **Hacker Prompts Dataset** is a multilingual text classification dataset specifically designed for detecting jailbreak and prompt injection attempts. It consists of the following fields:

- `prompt`: A string feature containing the input text.
- `label`: A string feature representing the classification label, which can be either `benign` or `malicious`.

## Embeddings Tested

### [distiluse-base-multilingual-cased-v1](https://huggingface.co/sentence-transformers/distiluse-base-multilingual-cased-v1)
- 512-dimensional vectors
- 14 languages
- Based on DistilBERT
- 135M parameters

### [distiluse-base-multilingual-cased-v2](https://huggingface.co/sentence-transformers/distiluse-base-multilingual-cased-v2)
- Same as v1 but supports 50 languages

### [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small)
- 384-dimensional vectors
- 94 languages
- Based on MiniLM-L12-H384
- 118M parameters

### [modernbert-embed-base](https://huggingface.co/nomic-ai/modernbert-embed-base)
- 768 dimensions (truncatable to 256)
- English only
- 149M parameters
- Based on ModernBERT with Matryoshka Representation Learning

### [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)
- 384-dimensional vectors
- 50 languages
- 118M parameters
- Optimized for paraphrase detection
