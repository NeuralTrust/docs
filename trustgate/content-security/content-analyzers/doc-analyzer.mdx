---
title: "Document Analyzer"
description: "Analyze uploaded documents for PII detection and content security"
---

The Document Analyzer plugin scans uploaded files (PDF, DOCX, images, etc.) for Personally Identifiable Information (PII) and other sensitive content before they are processed by your AI application.

## Features

- **Multi-format support**: PDF, DOCX, XLSX, PPTX, images (PNG, JPEG, TIFF)
- **PII detection**: Email, credit cards, phone numbers, national IDs, and more
- **OCR support**: Extract text from images and scanned documents
- **Configurable blocking**: Choose which PII entities trigger blocking

## Configuration

```json
{
  "name": "doc_analyzer",
  "enabled": true,
  "stage": "pre_request",
  "settings": {
    "mode": "enforce",
    "entities": [
      "email",
      "credit_card",
      "iban",
      "phone_number",
      "spanish_dni",
      "spanish_nie"
    ],
    "max_file_size": 52428800
  }
}
```

## Settings

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| `mode` | string | `enforce` (block) or `observe` (log only) | `enforce` |
| `entities` | array | List of PII entity types to detect | `[]` |
| `max_file_size` | integer | Maximum file size in bytes | `52428800` (50MB) |

## Supported PII Entities

| Entity | Description |
|--------|-------------|
| `email` | Email addresses |
| `credit_card` | Credit card numbers |
| `iban` | International Bank Account Numbers |
| `phone_number` | Phone numbers |
| `spanish_dni` | Spanish National ID |
| `spanish_nie` | Spanish Foreigner ID |
| `ssn` | Social Security Numbers |
| `passport` | Passport numbers |

## Modes

### Enforce Mode

When `mode` is set to `enforce`, the plugin will:
- Block requests containing files with detected PII
- Return a `403 Forbidden` response with details about detected entities

### Observe Mode

When `mode` is set to `observe`, the plugin will:
- Log detected PII without blocking the request
- Allow the request to proceed
- Record findings in observability data

## Example Response (Blocked)

```json
{
  "error": "PII detected in document",
  "status": 403,
  "details": {
    "entities_found": ["email", "credit_card"],
    "mode": "enforce"
  }
}
```

## Use Cases

1. **Data Loss Prevention**: Prevent sensitive data from being sent to AI models
2. **Compliance**: Ensure GDPR, CCPA, and other regulatory compliance
3. **Audit Trail**: Log all PII detection events for security audits
