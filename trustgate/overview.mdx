TrustGate is an [open-source](https://github.com/NeuralTrust/TrustGate) AI gateway
for LLM and MCP traffic. Point an OpenAI, Anthropic, or Responses client at it,
then route, authenticate, apply policy, and record every call from one place.

Configure it in the NeuralTrust console or the control-plane API.

## Core objects

Everything in the console under **TrustGate** is one of these:

| Object | What it is |
|---|---|
| **[Gateway](/trustgate/concepts/gateways)** | The top-level tenant. Owns everything below. |
| **[Registry](/trustgate/concepts/registries)** | An upstream backend: an LLM provider or an MCP server. |
| **[Consumer](/trustgate/concepts/consumers)** | The calling application's identity. Owns routing and credentials. |
| **[Auth](/trustgate/concepts/auth)** | A credential (API key, OAuth2, OIDC) that authenticates as a consumer. |
| **[Policy](/trustgate/policies/overview)** | Rate limits, budgets, tool governance, guardrails, and other controls. |
| **[Role](/trustgate/concepts/roles)** | Routing selected from OIDC token claims. |

## Request path

```text
client ──▶ /{consumer_slug}/v1/chat/completions
              │  X-AG-API-Key
              │  X-AG-Gateway-Slug (Private only)
              ├─ resolve gateway + consumer + policies
              ├─ apply policies (rate limit, budgets, guardrails, …)
              ├─ route across the consumer's registries (+ fallback)
              ├─ forward to the provider adapter
              └─ export telemetry → OpenTelemetry
```

The client names a **model** or uses `auto`. It does not send a provider URL or
key. [Architecture](/trustgate/architecture) covers the full lifecycle.

## FAQ

<AccordionGroup>
<Accordion title="Can I move an existing OpenAI or Anthropic client?">
Yes. Change the base URL and replace the provider credential with a TrustGate
consumer credential. TrustGate accepts OpenAI Chat Completions, Responses,
Anthropic Messages, and Google Gemini formats, then adapts the request for the
selected upstream. Start from the connection snippet on the consumer **Connect**
tab.
</Accordion>
<Accordion title="API key, OAuth2, or OIDC?">
Use an API key for a static application. OAuth2 validates service tokens or
brokers login for MCP clients. OIDC validates JWTs and can route from token
claims. See [Authentication](/trustgate/concepts/auth).
</Accordion>
<Accordion title="Can TrustGate run in my environment?">
Yes. Hybrid keeps the data plane in your network. External runs the full
platform yourself. SaaS hosts both planes. Compare models in
[Deployment](/neuraltrust/deployment/overview).
</Accordion>
<Accordion title="Do applications need the provider's credentials?">
No. Provider credentials stay on the registry. Applications authenticate as a
consumer. Rotate consumer keys separately from provider keys.
</Accordion>
</AccordionGroup>
