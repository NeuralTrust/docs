TrustGate exposes a **control-plane REST API** on the Admin plane. The NeuralTrust console uses it under the hood. You can call the same endpoints from automation, CI, or self-hosted operators when you need programmatic access.

Day-to-day setup for most teams still starts in the
**[console](/trustgate/getting-started/quickstart)**. Use this API for scripts, infrastructure-as-code style workflows, or integrations that skip the UI.

The **API reference** in the sidebar is generated from the live OpenAPI specification (`trustgate/api/openapi.json`) and includes a request builder for each operation.

## Base URL

| Plane | Default port | Purpose |
|---|---|---|
| **Admin** | `8080` | Control plane — every route in this reference except the proxy sample. |
| **Proxy** | `8081` | Runtime LLM traffic (consumer credentials), not admin tokens. |
| **MCP** | `8082` | Runtime MCP traffic (consumer credentials). |

Self-hosted example:

```text
http://localhost:8080
```

SaaS and Hybrid admin hostnames come from your deployment (console **Settings** or your platform team). Path prefixes stay the same (`/v1/...`).

## Authentication

Almost every `/v1/...` route expects:

```http
Authorization: Bearer <token>
```

| Token | When to use |
|---|---|
| **Admin JWT** (HS256) | Self-hosted or short-lived ops. Signed with `SERVER_SECRET_KEY`. See [Server security](/trustgate/operate/server-security#admin-authentication). |
| **Machine access token** (RS256) | SaaS / Hybrid automation. Exchange `client_id` / `client_secret` for a short-lived, gateway-scoped token — see [Authentication](/trustgate/api/credentials). |

Probes under **system** (`/healthz`, `/readyz`, `/__/version`, `/health`) do not require a token.

Interactive-only routes (catalogs, playground traces, config-sync connections) accept console or admin JWTs and reject machine credentials. Gateway-scoped resources accept either token type when the scopes and gateway binding allow it.

### proxy

These run on the **Proxy** plane (`:8081`) with **consumer** credentials, not admin tokens. Every path is `/{consumer_slug}/{fixed_route}`. Unknown shapes return **404** — the Proxy is not an open reverse proxy.

Consumer auth: `X-AG-API-Key`, `x-api-key`, or `Authorization: Bearer ag_…` (and OAuth/OIDC when configured). On Private deployments, also send `X-AG-Gateway-Slug` unless the host already scopes the gateway. See [Quickstart](/trustgate/getting-started/quickstart) and [Auth](/trustgate/concepts/auth).

## Admin plane vs Proxy plane

| | **Admin** (`:8080`) | **Proxy** (`:8081`) / **MCP** (`:8082`) |
|---|---|---|
| Who calls it | Console, operators, automation | Your applications |
| Auth | Admin JWT or [Authentication](/trustgate/api/credentials) | Consumer API key / OAuth (`X-AG-API-Key`, `x-api-key`, `Authorization: Bearer ag_…`) |
| Typical paths | `/v1/gateways/...` | `/{consumer_slug}/v1/chat/completions`, `/v1/embeddings`, `/v1/files`, … |

For client connect snippets and `model: "auto"`, use the consumer **Connect** tab or
[Quickstart](/trustgate/getting-started/quickstart) — not the Admin plane.
