<p className="nt-lead">
  Every simulation has a sender address and a link, and both carry a domain.
  Use a built-in one to start; add your own when you want simulations that
  look like they come from a domain you control.
</p>

Manage them in **Phishing › Settings › Sending domains**, which has two tabs:
**Your domains** and **Built-in domains**.

## Which domain a simulation uses

1. The domain the template or campaign pins, if any.
2. Otherwise, your first domain that is verified and routed.
3. Otherwise, a **Built-in domain**, one per campaign.

The sender's display name comes from the template or the campaign.

## Add your own domain

Use a domain registered for this purpose, not your corporate domain: people
should be able to spot it once they look closely.

<Steps>

<Step title="Add it">
Click **Add domain** and enter it. You need the **Admin** role for Employee
Security.
</Step>

<Step title="Create the DNS records">
**Configure DNS** shows two records to create at your DNS provider:

| Type | Purpose |
| --- | --- |
| **TXT** | Proves the domain is yours |
| **CNAME** | Points the domain's links to NeuralTrust. For an apex domain, use an A or ALIAS record instead, as shown |
</Step>

<Step title="Check it">
Click **Check now**. DNS changes can take a while to spread.
</Step>

</Steps>

| Status | Meaning | Fix |
| --- | --- | --- |
| **Action needed** | Added; the DNS records haven't been checked yet | Create the records, then **Check now** |
| **Record not found** | The check didn't find the TXT record | **Fix DNS** |
| **Not routed** | Verified, but the domain doesn't point to NeuralTrust yet. Simulations keep using a built-in domain until it does | **Route DNS** |
| **Verified** | Ready. Simulations use your first verified domain | |

## Web filters and DNS security

Because simulations are placed straight in the mailbox, your email gateway
never sees them, so there's nothing to allow-list there. A web filter or DNS
security service can still block the link when the person clicks it, which
hides the click. If yours blocks new or uncategorized domains, allow your
sending domains, including the built-in ones listed in **Built-in domains**.
