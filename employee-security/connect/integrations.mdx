<p className="nt-lead">
  Beyond mail and your directory, TrustForce connects to the tools where your
  team gets alerts and where your auditors look for training evidence.
</p>

All of them live in **Settings › Employee Security › Integrations**. Each panel
shows **What it does**, **Before you start** and **Permissions requested**, and
has **Save and test** and **Disconnect**. You need the **Admin** role for
Employee Security.

## Chat and notifications

| Integration | What it does |
| --- | --- |
| **Slack** | Sends an alert for each malicious email to your alerts channel, if you set one. Delivers **Chat** simulations as direct messages from your own Slack app. Tells employees in a direct message when a lesson is assigned after a failed simulation. |
| **Microsoft Teams** | Sends an alert for each malicious email to a channel, through a Teams workflow. Alerts only: no simulations or direct messages. |

Slack needs a bot token with the scopes the panel lists: `chat:write`,
`im:write`, `users:read` and `users:read.email`. The last one matches each
employee's Slack account by email; people without one are skipped in chat
simulations.

## Compliance evidence

| Integration | What it does |
| --- | --- |
| **Vanta** | Keeps each person's security training status in sync, as training evidence. |
| **Drata** | Uploads a one-page completion certificate for each completed course, as security training evidence. |

Each course lists the compliance frameworks it covers. See
[Courses](/employee-security/training/courses#compliance-evidence).

## Directory

## Status

| Status | Meaning |
| --- | --- |
| **Connected** | Saved and tested |
| **Waiting for first request** | Saved; waiting for the other side to call (SCIM) |
| **Not tested** | Saved, but the test hasn't run |
| **Error** / **Sync failed** | The last test or sync failed; the panel says why |
| **Not available here** | Not offered on this deployment |
| **Not connected** | Not set up |
