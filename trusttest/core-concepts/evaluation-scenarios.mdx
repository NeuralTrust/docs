## Evaluation & Scenarios

The **Evaluation** system provides a robust framework for evaluating AI models through various test cases and interactions. It allows users to assess model performance across multiple dimensions, track successes and failures, and ensure the model meets specific predefined criteria. The system supports dynamic evaluation with detailed reports and visual feedback to offer deeper insights into the model's behavior.

### Evaluation Run

An **Evaluation Run** represents the overall result of running a particular test scenario. It aggregates the test case results, summarizes the performance metrics, and provides feedback on the model’s performance according to defined evaluation criteria.

#### Key Classes Involved:

- **InteractionResult**: Represents the result of an individual evaluation interaction. It captures details such as the question, the model's response, and the results of each evaluator.
- **TestCaseResult**: Represents the outcome of evaluating a specific test case, including a series of interactions and their individual evaluation results.
- **EvaluationRun**: Represents the final evaluation of an entire scenario, aggregating all test case results and providing methods to visualize overall success, failure, and performance statistics.

The `EvaluationRun` provides methods to display detailed statistics such as the total number of test cases, interactions, passed/failed test cases, and overall success rate.

#### How the Evaluation Run Works:
1. **Test Case Evaluation**: Each test case within a scenario is evaluated asynchronously. Test cases consist of a series of interactions, where the model’s responses are compared against predefined expectations.
2. **Interaction Evaluation**: For each interaction, the model's response is evaluated using an `EvaluatorSuite`, which applies different evaluators to assess the quality of the response.
3. **Results Aggregation**: The `EvaluationRun` aggregates all the results from the test cases, calculates pass/fail rates, and generates a summary report with detailed results.

#### Summary of Evaluation Results:
The `EvaluationRun` class includes a **summary** property that provides the following information:
- **Total Test Cases**: The total number of test cases in the evaluation.
- **Total Interactions**: The number of individual interactions evaluated.
- **Passed and Failed Test Cases**: A breakdown of test cases that passed or failed.
- **Success Rate**: The percentage of test cases that passed out of the total.

You can display this summary using the `display_summary()` method, or you can examine individual test cases using `display()`.

### Evaluation Scenario

An **Evaluation Scenario** defines the specific set of tests and evaluation criteria for assessing a model’s performance. It combines a test set with evaluators and provides the logic to execute those tests. Each scenario can include multiple test cases, each focusing on a particular aspect of the model’s behavior.

#### Key Components of an Evaluation Scenario:
- **Scenario Name**: A descriptive name for the scenario.
- **Description**: A detailed explanation of what the scenario is testing or evaluating.
- **Evaluator Suite**: A collection of evaluators used to assess the model's responses. These evaluators can measure aspects like relevance, accuracy, and coherence.
- **Test Set**: A collection of test cases that define the interactions to evaluate, including the expected responses and other criteria.

The `EvaluationScenario` class facilitates the execution of a series of tests, running the evaluation asynchronously and generating an `EvaluationRun` that contains the results of all the test cases.

#### How the Evaluation Scenario Works:
1. **Test Set**: The test set is made up of **Test Cases**. Each test case consists of several **Interactions** (questions and expected responses).
2. **Evaluator Suite**: The **Evaluator Suite** applies evaluation criteria to each response. These criteria may include factors such as correctness, completeness, coherence, and relevance.
3. **Evaluate**: The `evaluate()` method runs the scenario and evaluates the interactions within the test set. It returns an `EvaluationRun` object that contains the results of all evaluations, aggregated into test case results.

#### Evaluation Process:
1. **Define the Test Set**: The test set contains a collection of interactions, each consisting of a question and an expected response. Each interaction is evaluated against predefined criteria.
2. **Apply Evaluators**: The **Evaluator Suite** applies various evaluation criteria to each model response, checking if it meets the expected quality standards.
3. **Aggregate Results**: Each interaction’s evaluation results are aggregated into a **TestCaseResult**. These results are then compiled into an **EvaluationRun** that provides a comprehensive summary of the model's performance in the scenario.

### Detailed Breakdown of Key Classes and Methods

#### `InteractionResult`

The **InteractionResult** class represents the evaluation of a single interaction in a test case. It contains:
- The **question** posed to the model.
- The **response** generated by the model.
- A list of **evaluations** performed by different evaluators.
- A flag indicating whether the interaction **failed**.
- The **context** within which the interaction took place, which may include additional information such as expected responses or descriptions of success/failure.

This class captures the granular details of how each interaction in the scenario is assessed.

#### `TestCaseResult`

The **TestCaseResult** class represents the result of evaluating a specific test case. It includes:
- A flag indicating if the test case **failed**.
- A list of **InteractionResults** for the test case.
- The **test_case_id**, **execution time**, and **execution date**.

This class encapsulates the results of a set of interactions for a given test case.

#### `EvaluationRun`

The **EvaluationRun** class aggregates the results from all test cases in an evaluation scenario. It includes:
- **Scenario ID**, **name**, **description**, and **fail criteria** used to determine overall success or failure.
- A list of **TestCaseResults** that summarize the results of each test case.
- **Summary** and **Display** methods to visualize the results in various formats, including the success rate, number of passed/failed test cases, and detailed evaluations of individual interactions.



# Conclusion
The Evaluation & Scenarios framework provides a flexible and powerful mechanism for assessing AI model performance. By using Test Sets, Evaluators, and Evaluation Scenarios, you can define comprehensive test suites to evaluate model accuracy, relevance, and other criteria. The results are aggregated into an EvaluationRun, which offers detailed insights into the model's performance and guides further improvements.

The EvaluatorSuite provides an essential mechanism for applying multiple evaluators to responses, ensuring the evaluation is thorough and covers all necessary aspects of model performance.
