title: Concepts

---

TrustTest evaluates a **target** by generating or loading **test cases**, scoring
them with **evaluators**, and grouping that work into an **evaluation scenario**
you can rerun.

| Object | Role |
|---|---|
| **[Test case](/trusttest/core-concepts/test-cases)** | One interaction: prompt, response, and the context used to score it. |
| **Probe** | Generates a set of test cases (jailbreak suite, dataset, RAG-derived, custom). |
| **Evaluator** | Pass / fail for a test case — heuristic or [LLM-as-judge](/trusttest/evaluate-result/llm-as-a-judge/overview). |
| **[Evaluation scenario](/trusttest/core-concepts/evaluation-scenarios)** | Binds a probe run to an evaluator suite and its failure criteria. |
| **Knowledge base** | Documents used as context when generating tests. |
| **Target** | The model, agent, or HTTP endpoint under test. |
| **Client** | Where scenarios and results are stored — local files or NeuralTrust. |

You do not have to use every object on the first run. A
[quickstart](/trusttest/getting-started/quickstart) is a target, a built-in probe,
and a client.
