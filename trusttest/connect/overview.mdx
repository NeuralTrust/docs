<p className="nt-lead">
  TrustTest is agnostic to the model under test. Connect a target, then attach
  probes and evaluators. The web UI currently requires an LLM that exposes a
  REST API.
</p>

<CardGroup cols={2}>
  <Card title="HTTP" icon="globe" href="/trusttest/connect/http">
    `HttpTarget` for any chat or completion endpoint, including multi-turn probes.
  </Card>
  <Card title="LLM providers" icon="sparkles" href="/trusttest/connect/llms">
    OpenAI, Azure, Anthropic, Google, Groq, Ollama, vLLM, and generic HTTP judges.
  </Card>
  <Card title="Custom target" icon="code" href="/trusttest/connect/custom">
    Implement the target interface when the system is not HTTP.
  </Card>
  <Card title="Results client" icon="hard-drive" href="/trusttest/connect/client">
    Write JSON locally, or persist the same artifacts in NeuralTrust.
  </Card>
</CardGroup>

Run TrustTest in a separate process from the model. In-process evaluation
  couples failures and makes multi-turn probes harder to reproduce.
