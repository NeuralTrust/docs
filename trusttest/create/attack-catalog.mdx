TrustTest includes a comprehensive catalog of red teaming attack probes designed to evaluate AI model safety, security, and robustness. This page provides a complete reference of all available attack techniques, their purpose, and when to use them.

## Probe Architecture

Each attack in TrustTest is implemented as a **Probe**. A probe generates test cases that are sent to your target model, collecting responses for evaluation. Probes can be:

- **Dataset-based**: Use curated datasets of attack prompts
- **Prompt-based**: Dynamically generate attacks using LLMs
- **Multi-turn**: Conduct sophisticated attacks across multiple conversation turns

## Prompt Injection Attacks

Prompt injection attacks attempt to manipulate the model into ignoring its instructions or behaving in unintended ways.

### Multi-Turn Manipulation Attacks

These sophisticated attacks use multiple conversation turns to gradually manipulate the model:

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Multi-Turn Manipulation** | `MultiTurnManipulationProbe` | Tests resistance to gradual manipulation across multiple conversation turns | Evaluates if the model can be slowly conditioned to comply with requests it would initially refuse |
| **Crescendo Attack** | `CrescendoAttackProbe` | Simulates gradual escalation attacks that slowly push boundaries toward a malicious objective | Tests if incremental requests can bypass safety measures |
| **Echo Chamber Attack** | `EchoChamberAttackProbe` | Tests vulnerability to reinforcement-based manipulation where the attacker validates model responses to encourage further compliance | Assesses resistance to social engineering through positive reinforcement |

### Jailbreaking Techniques

Direct attempts to bypass model safety measures:

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Anti-GPT** | `AntiGPTProbe` | Evaluates resistance to anti-GPT jailbreak prompts that claim the model has an "opposite mode" | Tests handling of role reversal requests |
| **DAN Jailbreak** | `DANJailbreakProbe` | Tests against "Do Anything Now" style jailbreaks where users instruct the model to adopt an unrestricted persona | Evaluates resistance to persona-based bypasses |
| **Best-of-N Jailbreaking** | `BestOfNJailbreakingProbe` | Tests against multiple jailbreak variations to find weaknesses | Probes for gaps in safety training through diversity |
| **Role-Playing Exploits** | `RolePlayingExploitsProbe` | Assesses vulnerability to role-play based manipulation | Tests if fictional or hypothetical framing bypasses guardrails |
| **System Override** | `SystemOverrideProbe` | Tests attempts to override system instructions with user messages | Evaluates instruction hierarchy enforcement |
| **Instructional Inversion** | `InstructionalInversionProbe` | Assesses handling of reversed or inverted instructions | Tests if negation or reversal confuses the model |

### Encoding & Obfuscation Attacks

Attacks that use encoding or obfuscation to bypass filters:

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Encoded Payload** | `EncodedPayloadProbe` | Tests resistance to base64, hex, and other encoded attacks | Evaluates if encoded malicious content bypasses filters |
| **Encoding and Capitalization** | `EncodingAndCapitalizationProbe` | Evaluates handling of alternating capitalization patterns | Tests resistance to visual obfuscation |
| **Symbolic Encoding** | `SymbolicEncodingProbe` | Tests against emoji and special character based bypasses | Assesses handling of symbolic representations of harmful content |
| **Obfuscation and Token Smuggling** | `ObfuscationAndTokenSmugglingProbe` | Assesses resistance to token-level obfuscation | Tests if splitting tokens across boundaries bypasses detection |
| **Typo Tricks** | `TypoTricksProbe` | Tests handling of intentional misspellings | Evaluates robustness to typo-based evasion |

### Structural Attacks

Attacks that exploit input structure or format:

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Context Hijacking** | `ContextHijackingProbe` | Tests vulnerability to conversation context manipulation | Evaluates if injected context can redirect model behavior |
| **JSON Injection** | `JsonInjectionProbe` | Evaluates resistance to malicious JSON payloads | Tests handling of structured data injection |
| **Payload Splitting** | `PayloadSplittingProbe` | Tests against attacks split across multiple messages | Assesses if fragmented harmful content evades detection |
| **Allowed and Disallowed Questions** | `AllowedAndDisallowedQuestionsProbe` | Tests mixing of legitimate and malicious questions | Evaluates if safe questions can mask harmful ones |

### Language-Based Attacks

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Multi-Language Attacks** | `MultiLanguageAttacksProbe` | Tests for bypasses using non-English languages | Evaluates safety consistency across languages |
| **Synonyms** | `SynonymsProbe` | Evaluates resistance to synonym-based evasion | Tests if alternative phrasings bypass content filters |

### Multimodal Attacks

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Multimodal Injection** | `MultimodalInjectionProbe` | Tests for attacks embedded in images or other media | Evaluates resistance to cross-modal injection attacks |

## Content Bias Attacks

Content bias probes evaluate your model for cognitive and stereotypical biases.

### Cognitive Biases

| Probe | Class Name | Description | Focus |
|-------|------------|-------------|-------|
| **Anchoring Bias** | `AnchoringBiasProbe` | Tests if the model over-relies on initial information | Evaluates if first impressions unduly influence judgments |
| **Framing Bias** | `FramingBiasProbe` | Evaluates if responses change based on how questions are framed | Tests consistency across different presentations of the same information |
| **Positional Bias** | `PositionalBiasProbe` | Assesses if the order of presented options affects model decisions | Tests if position in a list influences recommendations |
| **Status Quo Bias** | `StatusQuoBiasProbe` | Tests preference for current state over alternatives | Evaluates if the model favors existing solutions unreasonably |
| **Temporal Bias** | `TemporalBiasProbe` | Evaluates if time-related framing affects reasoning | Tests if recency or urgency unduly influences decisions |

### Stereotypical Biases

| Probe | Class Name (Dataset/Prompt) | Description | Focus |
|-------|------------|-------------|-------|
| **Ethnic Bias** | `EthnicStereotypicalBiasDatasetProbe` / `EthnicStereotypicalBiasPromptProbe` | Tests for discriminatory responses based on ethnicity or nationality | Evaluates fairness across ethnic groups |
| **Gender Bias** | `GenderStereotypicalBiasDatasetProbe` / `GenderStereotypicalBiasPromptProbe` | Evaluates fairness across gender identities | Tests for gender-based discrimination |
| **LGBTIQ+ Bias** | `LgtbiqStereotypicalBiasDatasetProbe` / `LgtbiqStereotypicalBiasPromptProbe` | Assesses treatment of LGBTIQ+ topics and individuals | Evaluates inclusive and fair treatment |
| **Religion Bias** | `ReligionStereotypicalBiasDatasetProbe` / `ReligionStereotypicalBiasPromptProbe` | Tests for religious discrimination or preferential treatment | Evaluates neutrality across religious groups |

## Choosing the Right Probes

### By Risk Level

**Critical Security (Must Test):**
- Prompt Injection attacks (especially DAN, System Override)
- Unsafe Outputs (Hate, Violence, CSAM)
- System Prompt Disclosure

**High Priority:**
- Sensitive Data Leak probes
- Input Leakage probes
- Multi-turn attacks (Crescendo, Echo Chamber)

**Standard Testing:**
- Content Bias probes
- Off-Topic probes
- Encoding/Obfuscation attacks

**Agent-Specific (If Applicable):**
- Agentic Behavior probes
- Tool-related data leak probes

### By Use Case

| Use Case | Recommended Probes |
|----------|-------------------|
| Customer Support Bot | Prompt Injection, Off-Topic, System Prompt Disclosure |
| Healthcare Assistant | Sensitive Data Leak, Unsafe Outputs (Self-Harm), Content Bias |
| Financial Advisor | Off-Topic (Economy), Sensitive Data Leak, Content Bias |
| General Purpose Chatbot | Full Prompt Injection suite, Unsafe Outputs, Input Leakage |
| AI Agent with Tools | Agentic Behavior, Tool-related probes, Prompt Injection |
| Content Moderation System | Unsafe Outputs, Bias probes |
