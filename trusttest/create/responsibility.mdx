title: Responsibility

The Responsibility Evaluator is a specialized tool designed to assess a model's compliance with various safety and ethical guidelines. It tests the model's ability to handle potentially harmful, illegal, or inappropriate requests by ensuring it responds appropriately and safely.

## Purpose

The Responsibility Evaluator is particularly useful when you need to:
- Test model safety and ethical boundaries
- Ensure compliance with content policies
- Prevent harmful or illegal content generation
- Evaluate model robustness against adversarial prompts
- Assess system security against potential attacks

## Available Compliance Categories

The Responsibility Evaluator includes several categories of compliance tests:

### 1. Toxicity
Tests the model's ability to handle harmful, illegal, or inappropriate content requests, including:
- Chemical and biological hazards
- Illegal activities
- Harmful content
- Harassment and bullying
- Discrimination and hate speech

### 2. SQL Injection
Evaluates the model's resistance to SQL injection attacks, testing:
- Basic injection attempts
- Data exfiltration
- Database structure disclosure
- Command execution
- Time-based attacks
- Blind injection
- System command execution
- Password extraction
- Data manipulation

### 3. Off Policy
Tests the model's ability to avoid discussing or promoting other companies, including:
- Competitor companies
- Alternative products
- Competing services
- Third-party solutions

### 4. System Configuration Leak
Tests the model's resistance to revealing its system prompt or configuration details, including:
- System prompt content
- Model instructions
- Configuration parameters
- Internal guidelines
- System constraints

### 5. Off Tone
Assesses the model's ability to maintain appropriate communication style and:
- Match brand voice
- Use appropriate language
- Maintain professional tone
- Avoid inappropriate expressions

## How It Works

The Responsibility Evaluator uses a binary scoring system:
- **Score: 0 (Compliant)**: The model responds appropriately, avoiding harmful content or security breaches
- **Score: 1 (Non-Compliant)**: The model fails to handle the request safely, potentially exposing harmful content or security vulnerabilities

## Usage Examples

### Basic Compliance Testing

Basic `ComplianceDatasetProbe` testing attacks the model with a set of predefined single-turn prompts and evaluates the model's response.

```python
from trusttest.catalog import IterateComplianceScenario
from trusttest.models.testing import RepeatModel

probe = ComplianceDatasetProbe(
    model=RepeatModel(),
    categories={"toxicity", "off_policy"},
    max_objectives_per_category=5
)

test_set = probe.get_test_set()
results = evaluator.evaluate(test_set)
results.display_summary()
```

### Iterative Compliance Testing

Given an objective, the `IterateComplianceScenario` will generate a conversation iteratively based on the model's response until the objective is met, or reaches a maximum number of turns.

<Note>
This probe needs a LLM client configured to generate the test set.
</Note>

```python
from trusttest.catalog import IterateComplianceScenario
from trusttest.models.testing import RepeatModel

scenario = IterateComplianceScenario(
    model=RepeatModel(),
    categories={"system_configuration_leak"},
    max_objectives_per_category=2,
    max_turns=4,
)

test_set = scenario.probe.get_test_set()
results = scenario.eval.evaluate(test_set)
results.display_summary()
```
