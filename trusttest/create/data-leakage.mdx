title: Data Leakage

In this guide we will see how to configure and run a **Data Leakage Scenario** to evaluate if your LLM model properly handles requests that attempt to extract Personally Identifiable Information (PII) or sensitive data.

## Configure the Data Leakage Scenario

For this example, we'll create a data leakage scenario that tests the model's ability to protect sensitive information:

```python
from dotenv import load_dotenv
from trusttest.catalog import ComplianceScenario
from trusttest.models.testing import DummyEndpoint

load_dotenv()

scenario = ComplianceScenario(
    model=DummyEndpoint(),
    categories={"data_leak"},
    max_objectives_per_category=1,
    use_jailbreaks=False,
)
```

Let's break down the configuration parameters:
- `model`: The LLM model you want to evaluate (in this case, a dummy endpoint for demonstration)
- `categories`: Set to `{"data_leak"}` to specifically test for data leakage scenarios
- `max_objectives_per_category`: Maximum number of test objectives to generate per category
- `use_jailbreaks`: Whether to include jailbreak attempts in the evaluation

## Run the Evaluation

Once you have configured your data leakage scenario, you can run the evaluation with these simple steps:

```python
test_set = scenario.probe.get_test_set()
results = scenario.eval.evaluate(test_set)
results.display()
results.display_summary()
```

This will:
1. Generate a test set containing various attempts to extract sensitive information
2. Run the evaluation against your model
3. Display detailed results showing how your model handled each test case
4. Show a summary of the evaluation

## Complete Example

Here's a complete example that puts everything together:

```python [expandable]
from dotenv import load_dotenv
from trusttest.catalog import ComplianceScenario
from trusttest.models.testing import DummyEndpoint

load_dotenv()

# Configure the data leakage scenario
scenario = ComplianceScenario(
    model=DummyEndpoint(),
    categories={"data_leak"},
    max_objectives_per_category=1,
    use_jailbreaks=False,
)

# Run the evaluation
test_set = scenario.probe.get_test_set()
results = scenario.eval.evaluate(test_set)
results.display()
results.display_summary()
```

## Advanced Usage: Iterative Testing

For more thorough testing, you can use the `IterateComplianceScenario` which allows for multi-turn conversations to test how the model handles persistent attempts to extract sensitive information:

<Note>
This probe needs a LLM client configured to generate the test set.
</Note>

```python [expandable]
from dotenv import load_dotenv
from trusttest.catalog import IterateComplianceScenario
from trusttest.models.testing import RepeatModel

load_dotenv()

scenario = IterateComplianceScenario(
    model=RepeatModel(),
    categories={"data_leak"},
    max_objectives_per_category=2,
    max_turns=4,
)

test_set = scenario.probe.get_test_set()
results = scenario.eval.evaluate(test_set)
results.display_summary()
```

This advanced scenario:
- Tests the model across multiple conversation turns
- Allows for more sophisticated attempts to extract information
- Provides a more comprehensive evaluation of your model's data protection capabilities
