<p className="nt-lead">
  An evaluator returns pass or fail for a test case. Combine them in an
  evaluator suite, bind the suite to a scenario, and rerun the same plan after
  every change.
</p>

Use a heuristic when the check is exact (language, signature, string match). Use
an LLM judge when the check is semantic (correctness, tone, relevance). Most
catalog threat probes default to `TrueFalseEvaluator`.
