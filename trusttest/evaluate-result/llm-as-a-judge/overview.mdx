---
title: LLM as judge
sidebarTitle: Overview
description: Score TrustTest responses with another model when the check is semantic.
---

<p className="nt-lead">
  An LLM judge reads the response and the evaluation context, then returns pass
  or fail. Use it when a regex or n-gram score cannot capture the criteria.
  It costs an extra model call and can vary slightly between runs.
</p>

<CardGroup cols={2}>
  <Card title="Correctness" href="/trusttest/evaluate-result/llm-as-a-judge/correctness">

  <Card title="Tone" href="/trusttest/evaluate-result/llm-as-a-judge/tone">

Prefer an LLM judge over a heuristic when the criterion is semantic. Prefer a
  heuristic when you need a cheap, deterministic check.
