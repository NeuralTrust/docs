---
title: Installation
---

To install TrustTest python package

```bash
uv add trusttest
# install all optional dependencies
uv add trusttest --all-extras
# or
pip install trusttest
```

> TrustTest uses `uv` for project dependency management. While `pip` is fully supported, we encourage using `uv`.
> [Learn more about](https://github.com/astral-sh/uv)

## Optional Dependencies

TrustTest provides several optional dependencies to make the library as lightweight as possible. You can install based on your needs:

### RAG Integrations

- **Azure Search Integration**
  ```bash
  uv add "trusttest[rag-azure]"
  # or
  pip install "trusttest[rag-azure]"
  ```

- **Upstash Vector Integration**
  ```bash
  uv add "trusttest[rag-upstash]"
  # or
  pip install "trusttest[rag-upstash]"
  ```

- **Neo4j Integration**
  ```bash
  uv add "trusttest[rag-neo4j]"
  # or
  pip install "trusttest[rag-neo4j]"
  ```

### LLM Provider Integrations

- **Ollama Integration**
  ```bash
  uv add "trusttest[ollama]"
  # or
  pip install "trusttest[ollama]"
  ```

- **Google AI Integration**
  ```bash
  uv add "trusttest[google]"
  # or
  pip install "trusttest[google]"
  ```

- **OpenAI Integration**
  ```bash
  uv add "trusttest[openai]"
  # or
  pip install "trusttest[openai]"
  ```

- **Anthropic Integration**
  ```bash
  uv add "trusttest[anthropic]"
  # or
  pip install "trusttest[anthropic]"
  ```

You can also install multiple optional dependencies at once by combining them with commas:

```bash
uv add "trusttest[rag-azure,openai,anthropic]"
# or
pip install "trusttest[rag-azure,openai,anthropic]"
```
